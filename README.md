Connect 4

Physical board games force people to play in person, making it near impossible to play over a distance, making it hard for people to play with others who they aren't  able to meet with in person. This is meant to solve that problem by creating an online version of connect 4 that would allow for two players to connect together and play through the terminal.



Technologies:

Java
Git


MVP scope:

Creating the game Structure

1. Making player input
2. Implement win/loss logic
3. Implement valid move logic

5. Implement Client Server connection
